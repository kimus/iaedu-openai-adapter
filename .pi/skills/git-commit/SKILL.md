# Git Commit

## Workflow
1. Review the changed files.
2. Make sure the repo is linted, typed, and tested if relevant.
3. Summarize the change in one short commit message.
4. Commit only the intended files.

## Commit style
- Keep the subject short and imperative.
- Prefer conventional style when it fits, e.g. `feat: add skill starter files`.

## Before committing
- Remove accidental edits.
- Do not commit generated artifacts unless needed.
- Confirm the diff matches the intended scope.
